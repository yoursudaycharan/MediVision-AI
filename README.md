# 🩺 MediVision AI

AI-powered medical image analysis and healthcare assistant built using Streamlit, Gemini AI, and SQLite.

---

## 🚀 Features

- 📤 Upload medical images
- 🤖 AI-powered medical analysis using Gemini API
- 📊 Disease severity assessment
- 💡 Personalized health recommendations
- 🔊 Voice report generation
- 💊 Medicine reminder system
- 📈 Recovery progress tracking
- 🗂 Medical history management
- 🎨 Modern responsive UI/UX

---

## 🛠 Tech Stack

- Python
- Streamlit
- Gemini API
- SQLite
- Plotly
- Pillow
- gTTS

## 📥 Clone the Repository

```bash
git clone https://github.com/yoursudaycharan/MediVision-AI.git

Move into the project folder:
cd MediVision-AI

📦 Install Required Packages
pip install -r requirements.txt

🔑 Configure Gemini API Key

Create a .env file in the project root folder.

Add:
GEMINI_API_KEY=YOUR_API_KEY

▶️ Run the Application
streamlit run app.py

🌐 Open in Browser
http://localhost:8501
